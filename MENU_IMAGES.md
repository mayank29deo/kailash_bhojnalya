# Menu image checklist

Drop dish photos in `public/menu/` using **the exact filenames in this list**.
The menu cards auto-detect them — supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`.
Square or near-square crops work best; the card renders an 80×80 thumbnail.

If a file is missing, the card simply hides the thumbnail — no broken image.
You can ship in batches: priority items first, the rest later.

## Recommendations

- **Resolution:** 600×600 px is plenty (cards display at 80px, but the same image is reused on Retina screens).
- **Crop:** centered, dish fills most of the frame, minimal table/border in shot.
- **Format:** JPEG is fine for photos; WebP if you want smaller files.
- **File size:** aim for < 80 KB each — Vercel will serve them faster, and the menu page stays snappy with 80+ thumbnails.
